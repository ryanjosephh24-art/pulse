# Pulse — B2B API Observability & Telemetry Console

A high-density observability dashboard designed for backend engineering teams to monitor real-time throughput, regional latency distributions, and triage production incidents.

## Features
- **Real-Time Telemetry:** P99 latency tracking, active edge monitoring, and comparative sparklines.
- **Traffic Analysis:** Time-series area charts comparing active periods against baseline traffic.
- **Incident Explorer:** Filterable log explorer with HTTP status pills and regional edge codes.
- **Multi-Tenant State:** Workspace switching with status toasts and tier configurations.

## Tech Stack
- **Framework:** Next.js (App Router) & React
- **Styling:** Tailwind CSS
- **Components:** shadcn/ui
- **Charts:** Recharts
- **Icons:** Lucide React
